## 고재현

뭐든 일단 만들어 보는 발명가입니다.
요즘은 맥북 힌지, 폴드 화면, 애플펜슬처럼 기기에 원래 달려 있는 센서로 새로운 놀잇감을 만들고 있습니다.
[티엔티랩스](https://tntlabs.kr)를 운영하고 있고, 매일 만든 앱은 [포털](https://king-project-portal.gojaehyun.com)에 모아 두고 있습니다.

[gojaehyun.com](https://gojaehyun.com) · [tntlabs.kr](https://tntlabs.kr) · [포털](https://king-project-portal.gojaehyun.com)

### 대표작

- **[cellid](https://cellid.gojaehyun.com)** — 맥북 화면을 열고 닫으며 연주하는 첼로
- **[foldjump](https://foldjump.gojaehyun.com)** — 폴드를 접을 때마다 애벌레가 점프하는 게임
- **[clapgo](https://clapgo.gojaehyun.com)** — 박수 두 번 치고 말로 시키면 아이폰이 대신 움직이는 맥 앱
- **[irismirror](https://github.com/Gojaehyeon/irismirror)** — 눈을 감는 만큼 아이폰 카메라 조리개가 조여지는 실험
- **[jsonwatch](https://github.com/Gojaehyeon/jsonwatch)** — 시간·날씨·심박수를 코드처럼 보여 주는 애플워치 시계
- **[airwheel](https://airwheel.gojaehyun.com)** — 웹캠 앞에서 허공에 핸들을 돌리는 레이싱 게임
- **[soundchat](https://github.com/Gojaehyeon/soundchat)** — 초음파로 근처 기기와 글자를 주고받는 채팅 앱

### 직접 쓰는 도구

- **[ccquota](https://github.com/Gojaehyeon/ccquota)** — Claude Max 구독 여러 개의 남은 사용량을 한눈에 보는 메뉴바 앱
- **[dip](https://github.com/Gojaehyeon/dip)** — 버튼 하나로 딴짓하는 앱을 막는 iOS 앱
- **[macmirror](https://macmirror.gojaehyun.com)** — 아이폰·아이패드를 맥 보조 모니터로 쓰는 앱
- **[flowchart](https://github.com/Gojaehyeon/flowchart)** — 코드를 읽어 흐름도로 바꿔 주는 도구
