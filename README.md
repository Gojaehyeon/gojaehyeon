### 발명가 고재현

멀쩡한 기기를 보면 "이걸로 딴 거 할 수 있지 않나?"를 참지 못합니다.
맥북 힌지로 첼로를 켜고, 갤럭시 폴드를 접어서 애벌레를 점프시키고, 박수를 쳐서 아이폰을 부립니다.
쓸모는 대체로 나중에 생각합니다.

- 연구소 · [티엔티랩스](https://tntlabs.kr)
- 발명 일지 · [매일 하나씩 만든 것들](https://king-project-portal.gojaehyun.com)
