### 고재현 · Go

기기에 원래 있던 센서를 엉뚱한 입력으로 바꾸는 걸 좋아합니다.
맥북 힌지는 첼로 활이 되고, 갤럭시 폴드는 점프 버튼이 되고, 웹캠은 게임 컨트롤러가 됩니다.

[티엔티랩스](https://tntlabs.kr)를 운영하며 iOS·macOS·웹 앱을 만들고, 매일 하나씩 만드는 앱은 [포털](https://king-project-portal.gojaehyun.com)에 모아 둡니다.

---

#### 기기의 숨은 센서로

| | |
|---|---|
| [**cellid**](https://cellid.gojaehyun.com) | 맥북 힌지를 활처럼 켜는 첼로. 키보드는 음정, 화면 각속도가 활 |
| [**hinge-tone**](https://hinge-tone.gojaehyun.com) | 맥북 힌지 각도로 조작하는 웹 DJ 콘솔 |
| [**foldjump**](https://foldjump.gojaehyun.com) | 갤럭시 Z 폴드를 접을 때마다 애벌레가 점프하는 게임 |
| [**pencil-dino**](https://github.com/Gojaehyeon/pencil-dino) | Apple Pencil 스퀴즈로 점프하는 iPad 러너 게임 |
| [**irismirror**](https://github.com/Gojaehyeon/irismirror) | 눈을 감는 만큼 iPhone 후면 조리개가 조여지는 프로토타입 |
| [**soundchat**](https://github.com/Gojaehyeon/soundchat) | 초음파로 근처 기기와 한 글자씩 주고받는 무전기 채팅 |
