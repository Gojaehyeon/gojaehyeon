## 고재현

발명가. 기기에 이미 달린 센서로 아무도 안 시킨 걸 만듭니다.
[티엔티랩스](https://tntlabs.kr)를 운영하고, 매일 하나씩 만든 건 [여기](https://king-project-portal.gojaehyun.com)에 쌓입니다.

[gojaehyun.com](https://gojaehyun.com) · [tntlabs.kr](https://tntlabs.kr) · [발명 일지](https://king-project-portal.gojaehyun.com)

### 여기서 시작

- **[cellid](https://cellid.gojaehyun.com)** — 맥북 화면을 활처럼 켜는 첼로
- **[foldjump](https://foldjump.gojaehyun.com)** — 폴드를 접으면 애벌레가 뜁니다. 그게 전부입니다.
- **[clapgo](https://clapgo.gojaehyun.com)** — 박수 두 번 치고 말하면 아이폰이 알아서 움직입니다
- **[irismirror](https://github.com/Gojaehyeon/irismirror)** — 눈을 감으면 카메라도 눈을 감습니다
- **[jsonwatch](https://github.com/Gojaehyeon/jsonwatch)** — 애플워치 시계를 코드 에디터로. 시간도 JSON입니다.
- **[airwheel](https://airwheel.gojaehyun.com)** — 웹캠 앞 허공에서 핸들 돌리기
- **[soundchat](https://github.com/Gojaehyeon/soundchat)** — 초음파로 한 글자씩 주고받는 무전기

### 가끔은 쓸모 있는 것도

- **[ccquota](https://github.com/Gojaehyeon/ccquota)** — Claude Max를 여러 개 쓰는 사람만 공감할 메뉴바 앱
- **[dip](https://github.com/Gojaehyeon/dip)** — 버튼 하나로 딴짓 차단
- **[macmirror](https://macmirror.gojaehyun.com)** — 아이폰·아이패드를 맥 보조 모니터로
- **[flowchart](https://github.com/Gojaehyeon/flowchart)** — 남이 짠 코드를 흐름도로 되돌리기
